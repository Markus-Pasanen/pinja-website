# Project Overview

Welcome to the documentation for the Jalkaterapia Pinja Website.

This project is the official website for Jalkaterapia Pinja, providing information about services, contact details, and business hours. The site is designed to be modern, responsive, and easy to maintain.

## Key Features

- Modern, mobile-friendly design
- Service descriptions and contact information
- Built with Next.js and TypeScript
- Styled using Tailwind CSS
- Dockerized for easy deployment

## Purpose

The website aims to:
- Present Jalkaterapia Pinja’s services and expertise
- Make it easy for clients to get in touch and book appointments
- Provide up-to-date business information
