# AGENTS.md

Guidance for AI agents and contributors working in this repository.

## Project

Static marketing website for **Jalkaterapia Pinja**, a foot-therapy practice in Varkaus, Finland.
Production: [jalkaterapiapinja.fi](https://jalkaterapiapinja.fi), hosted on GitHub Pages from
`main` (custom domain via `CNAME`).

- All visible content is **Finnish**. Keep `<html lang="fi">` on every page.
- No `package.json`, no dependencies, no build pipeline. HTML, CSS, and vanilla JS are edited
  directly and committed as-is.
- Do not add a framework, bundler, package manager, or build step unless the task explicitly
  calls for it.

## Local development

```bash
node dev/server.js
# → http://localhost:3000
```

`dev/server.js` is a zero-dependency static server. It serves the repository root, maps `/` to
`index.html`, and resolves extensionless paths to `.html` (so `/hinnasto` works locally).

Python fallback (no clean-URL support):

```bash
python -m http.server 8000
```

There is no install or build step.

## Styling

- **All pages use `style.css`.** It contains hand-written utility classes in Tailwind style
  (`text-sm`, `font-medium`, `px-g2`, `mt-g3`, `opacity-0`, `pointer-events-none`, `hover:*`,
  `sm:*`, `lg:*`) plus components such as `.btn-primary`, `.nav-glass`, `.glass-card`, and
  `.fade-in`.
- **There is no Tailwind CDN, config, or build step.** Add or change utility classes directly
  in `style.css`.
- Spacing uses the golden-ratio scale `--g0`…`--g8` defined in `style.css`. Prefer `p-g2`,
  `gap-g2`, `mb-g3`, etc. over arbitrary values.
- Match the design of the page you are editing. Do not introduce a second stylesheet or
  redesign pages unless the task explicitly asks for it.

## Shared JavaScript (`main.js`)

Loaded by every page. It provides:

- Mobile menu — `#menu-toggle`, `#mobile-menu-overlay`; toggles `opacity-*` /
  `pointer-events-*` state classes.
- Navbar glass effect on scroll — `#navbar` + `.nav-glass`.
- Scroll reveals — `.fade-in`, `.fade-in-right`, `.fade-in-left`, `.fade-in-scale` →
  `.visible`.
- Copyright year — `.js-current-year`.
- Facebook feed — fetches `public/facebook-posts.json`, renders up to 3 cards into
  `#facebook-posts`, opens `#facebook-post-dialog`.

Keep those IDs and classes when editing headers, footers, or the news section. Only the
homepage has the feed markup; other pages cause the feed code to exit early.

## Asset paths

- Root pages: `style.css`, `main.js`, `public/...`.
- Pages in `services/`: `../style.css`, `../main.js`, `../public/...`.

Adjust every path when copying a header or footer between root pages and `services/`.

## Facebook feed (Ajankohtaista)

Homepage news cards are read from `public/facebook-posts.json`, generated by a scheduled
GitHub Action.

```bash
FACEBOOK_RSS_URL="https://rss.app/feeds/ccdznoabxNawUrUP.xml" node scripts/fetch-facebook-posts.mjs
```

- `.github/workflows/facebook-feed.yml` runs daily at 05:17 UTC and commits
  `public/facebook-posts.json` plus `public/images/facebook/`.
- The RSS URL is defined in both the workflow and the script fallback; update both if it
  changes.
- The script uses Node 20 `fetch`, downloads post images, and leaves the existing JSON
  untouched if the feed fails. No secrets or API tokens are used.
- If the JSON is missing or empty, the homepage shows a "follow on Facebook" fallback card.

## Contact form

`yhteystiedot.html` posts to **SimplyForms** via an inline submit handler and redirects to
`/kiitos` on success. Fields: `name`, `email`, `phone`, `message`. Keep `kiitos.html` in the
repository root. The Web3Forms/hCaptcha notes in `README.md` are stale.

## Content and SEO conventions

- Every page needs a unique `<title>`, meta description, canonical URL, Open Graph tags, and
  Twitter Card tags. The homepage also has JSON-LD `MedicalBusiness` structured data.
- Canonicals use clean URLs (e.g. `https://jalkaterapiapinja.fi/esittely`). Production serves
  root pages at clean URLs as well as `.html`.
- **Known URL mismatch:** service pages live at `services/<slug>.html` and internal links use
  that path, but their canonicals and `public/sitemap.xml` entries use `/palvelut/<slug>`,
  which 404s in production. If you touch this area, fix links, canonicals, and sitemap
  together instead of copying the mismatch.
- **SEO files are under `public/`.** `public/sitemap.xml` is served at `/public/sitemap.xml`,
  not `/sitemap.xml`, and `public/robots.txt` points to the missing root sitemap path. Treat
  this as a known issue.
- When adding a page, add it to `public/sitemap.xml`, and update `lastmod` for pages whose
  content changed.
- Prices are duplicated in `hinnasto.html` and the matching `services/*.html` page (and
  sometimes in meta descriptions). Update every mention when a price changes.
